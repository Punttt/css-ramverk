Tailwind

Tailwind CSS är ett utility-first CSS-ramverk där man bygger designen direkt i HTML med små, återanvändbara klasser. Istället för färdiga komponenter får man byggstenar för till exempel avstånd, färger, typografi och layout, och kombinerar dem fritt till sin egen design.

Om ramverket

Tailwind skapades av Adam Wathan och släpptes 2017. I dag är det ett av de mest använda CSS-ramverken.

Det som skiljer Tailwind från till exempel Bootstrap är att det inte finns några färdiga knappar eller menyer. Istället får man byggstenar som man sätter ihop själv. Vill man ha padding skriver man p-4, och vill man ha grön bakgrund skriver man bg-green-800. Det gör att man har full koll på hur allt ser ut, men det kräver också mer jobb.

För att få sidan att fungera på olika skärmstorlekar lägger man till ett prefix före klassen, till exempel md: som bara gäller på större skärmar. På samma sätt fungerar hover: för när man för musen över något.

Jag installerade Tailwind via npm och kopplade det till Vite, som jag använde som utvecklingsmiljö. När sidan byggs tar Tailwind bara med de klasser jag faktiskt har använt, så CSS-filen blir liten.

Utvärdering

I början kändes Tailwind lite grötigt. Det finns väldigt många klasser och jag behövde slå upp nästan allt i dokumentationen. Men när jag väl lärt mig de vanligaste, som margin, padding, färger och flex, gick det snabbt att bygga, eftersom jag aldrig behövde lämna HTML-filen. Jag tror att Tailwind blir väldigt effektivt när man har kommit in i det.

Fördelar

  • Stylar direkt i html filen
  • ingen namngivning av klasser
  • smidigt att göra responsivt med md:
  • bara klasser som används i färdiga bygget

Nackdelar

  • Brant inlärningskurva i början, mycket att slå upp
  • lång listor gör html lite svårläst
  • mycket upprepning i tabeller i formulär
  • inga färdiga komponenter, hamburgemeny krävde egen JS
