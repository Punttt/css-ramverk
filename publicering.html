Publicering

Jag valde att publicera sidan på Netlify. Det är gratis, enkelt att komma igång med och kopplas direkt till GitHub, så sidan uppdateras automatiskt när jag pushar kod.

Läs mer om Netlify

Om Netlify

Netlify är en plattform för att publicera webbplatser. Man kopplar ett git-repo och Netlify bygger och publicerar sidan åt en. Det passar bra för statiska sidor och projekt byggda med till exempel Vite, React eller Astro, men det går också att köra serverfunktioner.

Kodstöd och kostnad

Kodstöd

Själva sidan kan vara byggd med vanlig HTML, CSS och JavaScript eller med ett ramverk eller byggverktyg som Vite. För kod som körs på servern, så kallade Netlify Functions, stöds JavaScript, TypeScript och Go.

Kostnad

Det finns en gratisplan med 300 krediter i månaden, som räcker gott för mindre projekt som det här. Den har bland annat obegränsade förhandsvisningar och egna domäner med SSL. Behöver man mer finns betalplaner, från 9 dollar i månaden för Personal och 20 dollar för Pro.

Så publicerar jag

  1. Jag lägger upp projektet i ett git-repo på GitHub.
  2. Jag skapar ett nytt projekt i Netlify, kopplar det till repot och anger byggkommandot npm run build och mappen dist.
  3. När jag har gjort ändringar lokalt committar och pushar jag dem till GitHub.
  4. Netlify märker den nya pushen, bygger sidan och publicerar den uppdaterade versionen automatiskt.

Utvärdering

Netlify var enkelt att komma igång med. Det tog bara några minuter att koppla repot och få sidan publicerad, och sedan behövde jag aldrig tänka på det igen. Det enda som störde lite var att det ibland tog en stund innan ändringarna syntes efter en push.

Fördelar

  • Enkelt att komma igång
  • Gratis för mindre projekt
  • Bra koppling till GitHub, publicerar automatiskt vid push
  • Går att anpassa, till exempel byta sidans namn eller lägga till egen domän

Nackdelar

  • Kan kännas lite segt ibland
  • Uppdateringar från git kan dröja innan de syns
